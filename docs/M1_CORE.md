# M1 — системное ядро

Статус: завершён 22 июля 2026 года.

M1 реализует симуляцию одной попытки без привязки к UI и готовому игровому контенту. Все изменения состояния проходят через общие условия, эффекты и атомарные транзакции.

## Что реализовано

- `RunState` с календарём и возрастом, пятью показателями состояния, деньгами, инвентарём, знаниями, журналом и отложенными последствиями;
- Сила, Харизма, Интеллект и Удача в диапазоне `1–10` с обязательным общим бюджетом `18`;
- шесть хранимых шкал полярностей и два вычисляемых профиля, которые формируются только после накопления достаточных свидетельств;
- шесть тестовых навыков с рангами `0–3` и общие очки освоения;
- единый язык `Condition` / `Effect`, `CheckResolver` и объяснимые причины блокировки;
- транзакции действий по правилу «всё или ничего»;
- дискретное время, которое меняется только эффектом подтверждённого действия;
- детерминированный RNG с сохраняемыми `seed` и внутренним состоянием;
- версионированное JSON-сохранение с проверкой временного файла и резервной копией.

## Основные инварианты

| Область | Правило |
|---|---|
| Характеристики | Ровно четыре целых значения `1–10`, сумма равна `18` |
| Показатели | Здоровье, Голод, Энергия, Напряжение и Мораль находятся в диапазоне `0–100` |
| Полярности | Хранимые шкалы находятся в диапазоне `-100…100`; несформированный вычисляемый профиль остаётся в центре |
| Навыки | Ранг `0` означает, что навык не открыт; игровые ранги находятся в диапазоне `1–3` |
| Время | Чтение состояния ничего не меняет; один эффект времени ограничен десятью календарными годами |
| Действие | Условия проверяются до эффектов; ошибка любого эффекта отменяет весь пакет |
| Числа в JSON | Целые payload-значения ограничены точным диапазоном JSON/IEEE-754 |

## Сохранение и восстановление

Сохранение сначала записывается в `.tmp`, перечитывается и проверяется, после чего прежний основной файл становится `.bak`, а проверенный временный файл — основным. При загрузке кандидаты проверяются в порядке:

1. валидный временный файл незавершённой записи;
2. основной файл;
3. резервная копия.

Временный файл имеет приоритет, потому что он содержит полностью записанное и уже проверенное более новое состояние; прежний валидный основной файл при этом сохраняется как резервный. Загрузка не сообщает об успешном восстановлении, пока валидный файл физически не установлен на основной путь. Валидный незавершённый `.tmp` также нельзя молча перезаписать новым автосохранением.

## Проверка

Headless-набор содержит 16 тестов: распределение характеристик, начальное состояние, условия, успешные и заблокированные транзакции, rollback, границы навыков и времени, точность JSON, RNG, календарь, полный цикл сохранения, восстановление `.tmp` и `.bak`, а также отказ при повреждении всех копий.

```powershell
godot --headless --path . --script res://tests/test_runner.gd
```

Ожидаемый итог: `M1 TESTS PASSED: 16/16`.

## Не входит в M1

Подключение автосохранения к жизненному циклу Android, UI, карта, события и первый игровой день относятся к следующим этапам. До перехода к многолетним историям журнал потребуется разбить на главы или архивные снимки, чтобы размер сохранения не рос неограниченно.
