# Бомжара

Текстовый survival-RPG для Android об обычном человеке, который начинает без ресурсов на улицах большого вымышленного города и решениями создаёт собственную жизненную историю.

## Техническая основа

- Godot 4.7;
- Mobile renderer;
- Android;
- сначала портретная, затем адаптивная альбомная компоновка;
- первая версия только на русском языке.

## Стартовый персонаж

Игрок распределяет ровно 18 очков между четырьмя характеристиками от 1 до 10: Силой, Харизмой, Интеллектом и Удачей. Отдельных стартовых черт, предыстории и готовых навыков нет. Полярности формируются поступками, а навыки приобретаются во время игры.
