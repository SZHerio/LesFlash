# Бомжара

Текстовый survival-RPG для Android об обычном человеке, который начинает без ресурсов на улицах большого вымышленного города и решениями создаёт собственную жизненную историю.

## Техническая основа

- Godot 4.7.1;
- Mobile renderer;
- Android;
- сначала портретная, затем адаптивная альбомная компоновка;
- первая версия только на русском языке.

## Стартовый персонаж

Игрок распределяет ровно 18 очков между четырьмя характеристиками от 1 до 10: Силой, Харизмой, Интеллектом и Удачей. Отдельных стартовых черт, предыстории и готовых навыков нет. Полярности формируются поступками, а навыки приобретаются во время игры.

M1 принят как системная основа. M2 завершён как технический эксперимент и покрыт headless-тестами, но его событийный UX и монолитный UI не являются продуктовым образцом. Реализация M3A завершена: приложение переведено на модульный `AppShell`, самостоятельные экраны и общий UI-контракт. Формальная приёмка M3A ожидает закрытия G0: на рабочей станции пока нет Android SDK/`adb`, а обязательная проверка на физическом устройстве не выполнена. После G0 следующий продуктовый этап — M3B, location-first sandbox.
